Entry for the make.fun bounty "How Many Tabs Do You Have Open?". The program writes one number to /output/entry.txt: 241, an honest tab count. The judge picks the more surprising count that still reads as real; 241 is high enough to startle, specific enough to sound counted rather than guessed, and it hints at a week of research rabbit holes behind it.

## Run it

```sh
python3 main.py
```

This writes `entry.txt` containing `241` to `/output` (or to `$MAKEFUN_OUTPUT_DIR` when that environment variable is set).
